# AgentHub 3 分钟 Demo 演示脚本

## 一、开场（15s）

**（画面：AgentHub 首页，展示完整三栏布局——左侧会话列表、中间聊天区、右侧协作剧场）**

大家好，我是 AgentHub 的开发者。AgentHub 是一个**多 Agent 协作平台**，它把 AI 协作做成像飞书、微信一样的 **IM 聊天体验**。你可以和单个 Agent 对话，也可以拉多个 Agent 进群聊，让它们协作完成复杂任务。

---

## 二、IM 聊天式交互（40s）

**（画面：鼠标移到左侧栏，依次点击「助手」「群聊」「话题」「归档」四个 Tab）**

先看左侧栏。这里有四个 Tab——助手、群聊、话题、归档。**助手**就是你的 Agent 联系人列表，每个 Agent 有名字、头像和能力标签，点击就能打开对话。**群聊**里是多人会话，一个群可以包含多个 Agent。**话题**按 Agent 分类展示你的历史对话。**归档**用来收纳不活跃的会话。

**（画面：点击一个 Agent，快速展示单聊界面，发送一条消息）**

单聊就跟微信聊天一样——输入需求，Agent 回复，支持多轮迭代。消息支持复制代码、引用回复、重新生成。

**（画面：切换到群聊 Demo，展示群聊里有 4 个 Agent 的成员列表）**

群聊是核心亮点。一个群里有多个 Agent，你只需像平常聊天一样发需求，系统会自动协调它们。

---

## 三、群聊多 Agent 协作（70s）—— 核心演示

**（画面：在 Demo 群聊中输入「帮我做一个个人博客页面，包含首页、文章列表和文章详情」）**

我现在发一个需求：帮我做一个个人博客页面。

**（画面：聊天区出现系统消息，Orchestrator 开始工作，Critic 先追问澄清需求）**

注意看——消息发出后，群里的 **Orchestrator 编排器**开始自动运作。它先走**需求澄清阶段**，Critic Agent 会追问关键信息，比如「需要响应式吗」「要哪些页面」。

**（画面：用户回复澄清后，系统显示 Planner 正在分解任务）**

澄清完成后自动进入**方案对比阶段**，Planner 给出不同技术方案的对比。选定方案后，Planner **一次性拆解出完整的任务执行计划**。

**（画面：聚焦右侧「协作剧场」面板，展示任务时间线——设计 → 编码 → 验证）**

这时候看右边——**协作剧场**。Planner 把任务拆成了清晰的步骤：第一步设计页面结构，第二步编写 HTML，第三步编写 CSS，第四步功能验证。每个任务标注了依赖关系和执行者，一目了然。

**（画面：任务逐个变绿，Agent 头像旁的脉冲动画展示正在执行）**

然后**自动按顺序执行**——设计完成后编码自动开始，编码完成后验证自动触发。每个任务的状态实时更新，跑马灯动画展示当前正在执行谁。全部完成后底部进度条走满，一条绿色完成线贯穿时间轴。

这就是**从需求到交付的全自动协作流程**——你只需要发需求，规划、分配、执行、验证全由系统搞定。

---

## 四、产物预览（25s）

**（画面：滚动聊天记录，展示 Agent 回复中的代码块、Diff 卡片、网页预览卡片）**

Agent 的回复不只是文字。代码块支持语法高亮和**一键复制**。多轮修改时会展示 **Diff 视图**，增删改一目了然。最终产物还能以**网页预览卡片**的形式直接嵌入聊天流，点击就能在右侧展开完整预览。

**（画面：点击预览卡片，展开全屏预览）**

你不用离开聊天界面就能看到 Agent 交付的完整网页效果。

---

## 五、结尾（15s）

**（画面：回到首页全景，缓慢拉远）**

总结一下，AgentHub 用 **IM 的交互范式**降低了多 Agent 协作的门槛——像聊天一样发需求，像看群消息一样跟进进度。Orchestrator 自动编排、协作剧场透明展示、产物内联预览。这就是 AgentHub，让 AI 协作像聊天一样简单。

谢谢观看。
