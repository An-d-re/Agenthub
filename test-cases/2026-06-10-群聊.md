### 核心逻辑流程图

```
用户点击"开始"
  → setInterval(tick, 1000) 启动
  → tick() 每秒执行：
      1. remaining--
      2. 如果 remaining <= 0：
         → setPhase(!isWorkPhase) 切换阶段
         → 重置 remaining 为新阶段总秒数
         → 继续倒计时（保持运行）
      3. 否则：renderTime() 更新显示
用户点击"暂停"
  → clearInterval(timerId)
  → isRunning = false
用户点击"重置"
  → 停止计时器
  → remaining = 当前阶段初始值
  → 更新显示
```
