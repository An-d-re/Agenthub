## 环境准备

确保后端 8000 + 前端 3000 已启动，DeepSeek API Key 已配置。

## 步骤

用户：创建一个 index.html 文件，包含 hello world 标题
(等待 Agent 回复完成，等待文件产出和 DiffCard 出现)
(点击应用按钮，将文件写入 workspace)
用户：在 index.html 的 body 中添加一个段落 p 标签，内容是 "这是第一段"
(等待 Agent 回复，点击应用)
用户：把 index.html 的 title 改成 "新标题"
(等待 Agent 回复)

(点击应用按钮)
(观察是否出现 "已合并" 或冲突提示)
(如果是自动合并，应显示 "✓ 已合并")

## 验证要点

两个 Agent 修改同一文件的不同区域时，应自动合并无冲突，显示 "✓ 已合并" 而非报错。
