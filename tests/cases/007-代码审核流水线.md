## 步骤

用户：请写一个 Python 函数实现二分查找（binary search），要求完成以下四个环节：
1. 一个Agent负责编写二分查找函数代码（接收有序数组和目标值，返回索引或-1）
2. 第二个Agent依赖第一个Agent的代码，负责编写单元测试（覆盖：正常找到、未找到、空数组、单元素）
3. 第三个Agent依赖前两个的产出，负责审查代码正确性和边界情况处理
4. 第四个Agent汇总前面所有人的产出，写一份总结报告（包含：代码概述、测试覆盖情况、审查结论）
