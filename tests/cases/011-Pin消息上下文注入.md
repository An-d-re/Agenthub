## 环境准备

确保后端 8000 + 前端 3000 已启动，DeepSeek API Key 已配置。

## 步骤

用户：请记住这个数字：42，它很重要
(等待 Agent 回复，记录回复内容)

(在消息列表中右键点击用户发送的 "请记住这个数字：42，它很重要" 消息，找到 Pin 按钮并点击固定)

用户：我让你记住的数字是多少？
(等待 Agent 回复)
(检查 Agent 回复中是否提到 42)

## 验证要点

Agent 的第二条回复中应包含 "42"，说明 Pin 消息成功注入上下文。

## 重点截图

- Pin 按钮点击
- Agent 回复包含 42
